# Security policy

MATLAB files are structured binary input and may allocate substantial memory.
Only process files from trusted sources, verify published checksums where
available, and apply operating-system resource limits when scanning unknown
archives.

Please report a suspected vulnerability privately to the repository owner
instead of opening a public issue containing exploit details or sensitive
participant data. The project currently supports the latest development
version only; fixes will be released on the main branch until stable releases
are published.
